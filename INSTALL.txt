Oritasy's RADAR 0.0.6T

Install:
1. Install BepInEx 5 x64 (Mono) in the Nuclear Option game directory.
2. REQUIRED: install BIA Runtime (BIA.Runtime_*.dll, GUID bia.runtime / DisplayName "BIA Runtime")
   into Nuclear Option/BepInEx/plugins/. RDA has a hard BepInDependency on bia.runtime —
   Chainloader will not load RDA without it and will load RDA after BIA automatically.
3. Copy RDA.dll into Nuclear Option/BepInEx/plugins/.
4. Launch the game; BepInEx will load the plugin.

Plugin DisplayName: Oritasy's RADAR
BepInPlugin version (numeric SemVer): 0.0.6
DisplayVersion: 0.0.6T

Notes (0.0.6T):
- Press `/` to open the Oritasy-style settings menu (RADAR window position + opacity). Persists to BepInEx config.
- TWS auto-locks nearest + highest-threat air via vanilla WeaponManager.targetList (Radar.TwsAutoLock, default true).
- Datalink contacts stay continuous between ingest ticks (persistent hold cache — no flicker).
- Hard prerequisite: bia.runtime. Soft deps: com.iallemmege.oritasy / com.iallemmege.oritasyhud.
- DisableVanillaRadar default=false. Display.GuiDepth default=-1000.
- Harmony patches only vanilla NuclearOption types — never BIA* types.
- Toggle overlay with F6. BepInEx requires numeric SemVer in [BepInPlugin] (0.0.6); 0.0.6T is DisplayVersion.
- Default Display.HudGateMode=AircraftPresent; ForceShowHud=true is emergency bypass.
- Ensure Oritasy plugin files end with .dll (not .dl) if used. OritasyFonts/ optional.
