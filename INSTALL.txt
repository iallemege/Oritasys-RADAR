Oritasy's RADAR — Realtime Aerial Detection And Ranging (R.A.D.A.R.)

Requires:
- Nuclear Option with BepInEx 5 x64 (Mono)
- BIA Runtime (BIA.Runtime_*.dll, GUID bia.runtime) in BepInEx/plugins/

Install:
1. Install BepInEx 5 x64 (Mono) in the Nuclear Option game directory.
2. Install BIA Runtime into Nuclear Option/BepInEx/plugins/.
3. Copy RDA.dll into Nuclear Option/BepInEx/plugins/.
4. Launch the game.
